# Cailin Zhuang

Personal homepage of Cailin Zhuang (庄才林), a Ph.D. researcher at Fudan University and founder of AIGC Research.

The site is built with Jekyll and deployed through GitHub Pages:

<https://journey-zhuang.github.io/>

## Local development

Install Ruby, Bundler, and the dependencies in `Gemfile`, then run:

```bash
bundle install
bundle exec jekyll serve
```

The local preview is available at <http://localhost:4000>.
